# the-hurt-locker
I created this module so that I could more easily see and use the DM damage cards with midiqol in foundry vtt.  It creates a second window called the Hurt Locker that shows the DM damage cards for use.  


Known issue:  The cards in main chat don't update when the hurt locker ones do, syncing would add performance hits that are imo not important to risk so just use one or the other and understand whatever one you are prioritizing will be the one with correct buttons.
